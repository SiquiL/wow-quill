# Changelog

## 1.0.0

First release.

### Notes and notebooks

- Notes written in Markdown in an edit mode and shown formatted in a read mode
- Nested notebooks with their own colors, shared by the account or limited to one character
- Notes can be limited to the current character; titles are unique within a notebook
- Search by title and text, plus `tag:` and property filters

### Markdown

- Six heading levels, bold, italic, strikethrough, lists, checklists, tables, quotes, code and rules
- Text colors with `<font color>`
- Clickable wiki links (`[[Note]]`) to other notes, updated when a note is renamed
- Game hyperlinks for items, quests, spells and more, inserted with Shift-click
- YAML properties at the top of a note, and tags with `#` in properties and text

### Organizing

- Favorites section above all notebooks
- Trash for notes and notebooks with restore; entries are deleted after 7 days
- Undo and redo in the editor with Ctrl+Z and Ctrl+Y
- Adjustable text size

### Small note windows

- Read-only windows for single notes, e.g. a boss strategy during a fight
- Several windows at once, usable in combat, resizable and with their own text size
- A lock that keeps the window in place and lets clicks through

### Appearance and settings

- Standard and Custom Color themes with background opacity
- Settings panel, window reset, addon compartment entry and bug report link
- English and German
